# ROS 1 Noetic Simulation

This folder contains a curated subset of configuration from the original mobile-manipulator simulation workspace.

The full archive also included third-party packages and tutorial-derived source files. Those are intentionally excluded from this public repository.

## Included here

- navigation launch configuration
- AMCL configuration
- global/local costmap parameters
- local planner tuning

These files show how the simulated mobile manipulator was configured for map-based localisation and goal navigation in Gazebo/RViz.
