# Media

This folder contains selected figures from the Master's thesis **A ROS-Based Approach for Collaborative AMRs and Robotic Arms**.

Included figures:

- `fig25_navigation_rviz.png` - 2D navigation goal and RViz navigation view
- `fig35_moveit_goal.jpg` - robotic-arm motion toward a configured MoveIt goal pose
- `fig40_ros2_demo_pickup.jpg` - ROS 2 Humble pick-and-place demonstration

The original project also includes demonstration videos, but they are not stored in this repository because of file size.
