# Project Notes

This repository is being reconstructed from the original Master's-project workspace and demonstration material.

## Verified material currently available

- ROS 1 Noetic mobile-manipulator simulation
- Gazebo warehouse-style environment
- AMCL localisation
- move_base navigation
- global/local costmap configuration
- LiDAR and IMU simulation interfaces
- MoveIt configuration for the manipulator
- RViz configuration and saved maps
- ROS 2 Humble navigation demonstration
- navigation, goal-execution, and manipulation videos

## Important correction

The project did **not** use NVIDIA Jetson hardware. Earlier repository documentation mentioned Jetson incorrectly, and that reference has been removed.

## Public release approach

Only files that can be responsibly attributed to this project will be published.

The original archive contains third-party ROS packages and at least one tutorial-derived source file. Those files are being excluded or clearly attributed rather than presented as original work.

Machine-specific caches, build outputs, credentials, temporary files, nested Git repositories, and unrelated dependencies will also remain excluded.
