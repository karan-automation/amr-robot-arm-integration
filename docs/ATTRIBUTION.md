# Attribution and Source Review

This repository is a curated public version of a larger robotics project workspace.

## Third-party material intentionally excluded

### Hector SLAM
The original archive contains a full `hector_slam` source tree with its own Git metadata. This is third-party open-source software and is **not** being republished here as original project code.

### Send-goals example
The original `send_goals.cpp` file contains an explicit header crediting **Automatic Addison** and identifies itself as a ROS 1 Noetic example. It is therefore not being presented as original source code in this repository.

### Generated configuration
Some MoveIt configuration files were generated or scaffolded using the MoveIt Setup Assistant. Where included later, they will be described as generated configuration customised for the project.

## What this repository is intended to show

The purpose of this repository is to document my engineering work around:

- mobile-robot navigation configuration
- localisation and costmap tuning
- robot-model and simulator integration
- manipulation setup
- system-level testing and troubleshooting
- ROS / ROS 2 experimentation

The goal is accuracy and reproducibility, not claiming ownership of upstream ROS packages or tutorial code.
